# Documentação do NES-FREQUÊNCIA

Esta documentação descreve o sistema NES-FREQUÊNCIA, um projeto de controle de presença escolar com aplicativo web.

O objetivo é fornecer uma visão clara de toda a arquitetura, os componentes de frontend e backend, os endpoints da API e as etapas necessárias para executar e implantar o projeto.

## Conteúdo da documentação

- `docs/architecture.md` — visão geral da arquitetura, componentes e fluxo de dados.
- `docs/backend.md` — explicação detalhada do backend, estrutura de arquivos e comandos.
- `docs/frontend.md` — explicação do frontend, estrutura de arquivos e funcionamento das telas.
- `docs/api.md` — documentação completa dos endpoints da API e parâmetros de cada rota.
- `docs/deployment.md` — instruções de execução local e com Docker, incluindo seed de banco.

## Como navegar nesta documentação

1. Comece por `docs/architecture.md` para entender a estrutura global.
2. Leia `docs/backend.md` para conhecer o servidor, banco de dados e lógica de negócios.
3. Abra `docs/frontend.md` para entender a aplicação em React e o fluxo de autenticação.
4. Consulte `docs/api.md` para saber como usar cada rota da API.
5. Use `docs/deployment.md` quando for configurar ou iniciar o ambiente.
